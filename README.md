   ## How to Run

   1. **Build the project:**
      ```bash
      mvn clean package
      ```

   2. **Run with embedded Tomcat:**
      ```bash
      mvn tomcat7:run
      ```

   3. **Open in browser:**
      - Home: http://localhost:9000/
      - Assignment 1 (Login): http://localhost:9000/login.jsp
      - Assignment 2 (Redirect): http://localhost:9000/redirect.jsp

   ## Login Servlet

   - **URL:** `/login.jsp` (form) → `/login` (servlet)

   ## Send Redirect

   - **URL:** `/redirect.jsp` (form) → `/redirect` (servlet)
